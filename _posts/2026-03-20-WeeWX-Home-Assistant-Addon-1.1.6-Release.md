Today is an exciting milestone, with the [WeeWX Home Assistant Addon](https://github.com/dalethestirling/hassio-addons/tree/main/weewx) receiving its first ever patch release.

Version 1.1.6 has just gone live, and this update sees:

- Updated weewx to version 5.3.1 in the container
- Updated base container to use hassio-addons/base:20.0.1

New installations can add my Addons repository by:

1. Going to **Settings > Add-ons > Add-on Store**
2. Clicking the **top right menu > Repositories**
3. Adding `https://dalethestirling.github.io/hassio-addons/` to the list.

Existing users will get the update automatically displayed in Settings > Apps > WeeWX.
